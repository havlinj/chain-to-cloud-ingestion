# Progress (session recaps)

Chronological notes of **what was done** in a development session or milestone: context, files touched, commits, tests run, next steps.

Do **not** use this folder for forward-looking direction — put that in [`../planning/`](../planning/). Do **not** use it for final architectural decisions — put those in [`../ADR/`](../ADR/).

Naming: `session_N.md` or `YYYY-topic.md`.
